===============================================================================
                     CONFIGURATION MANUAL & FIELD GUIDE
===============================================================================

[ACTIVE PROFILE SELECTION]
-------------------------------------------------------------------------------
ACTIVE_PROFILE_ID             : Selects the active agent profile key loaded
                                from brain_library.yaml at engine boot.
                                Metric: Profile ID string (str).


[DISPLAY & GRID LAYOUT]
-------------------------------------------------------------------------------
SCREEN_WIDTH                  : Target display window width in pixels.
                                Metric: Pixels (int).

SCREEN_HEIGHT                 : Target display window height in pixels.
                                Metric: Pixels (int).

FPS                           : Target rendering frame rate and frame clock
                                cap for display synchronization.
                                Metric: Hertz (int).

VIEWPORT_GRID_ROWS            : Number of grid viewport rows in multi-window
                                mode. Metric: Rows count (int).

VIEWPORT_GRID_COLS            : Number of grid viewport columns in multi-
                                window mode. Metric: Columns count (int).

WINNER_CELEBRATION_FRAMES     : Frame buffer duration to celebrate maze solve
                                at exit tile. Metric: Frames count (int).


[WORLD & MAP PARAMETERS]
-------------------------------------------------------------------------------
MAP_TYPE                      : Selects procedural level generator style
                                ("BRANCHING WALLS" or "RANDOM").
                                Metric: Style string (str).

MAP_WIDTH                     : Level grid width in tile units.
                                Metric: Tiles (int).

MAP_HEIGHT                    : Level grid height in tile units.
                                Metric: Tiles (int).

TILE_SIZE                     : On-screen pixel size of a square tile in
                                player-centered tracking mode.
                                Metric: Pixels (int).

WALL_DENSITY                  : Target ratio of inner floor area to convert
                                into wall obstacles during generation.
                                Metric: Ratio [0.0 - 1.0] (float).

MAX_MAP_GEN_ATTEMPTS          : Max generator retry iterations to produce a
                                100% solvable layout before fallback.
                                Metric: Attempts (int).

MIN_PATH_DIFFICULTY_RATIO     : Minimum topological BFS step-distance ratio
                                required between start and exit tiles.
                                Metric: Ratio [0.0 - 1.0] (float).


[GENETIC ALGORITHM & TRAINING]
-------------------------------------------------------------------------------
LEARNING_GENERATIONS          : Total evolutionary generations simulated
                                during execution.
                                Metric: Generations count (int).

POPULATION_SIZE               : Total candidate neural networks evaluated
                                per evolutionary generation.
                                Metric: Candidates count (int).

MAPS_PER_CANDIDATE            : Number of independently-seeded procedural mazes
                                evaluated per candidate genome.
                                Metric: Mazes count (int).

SIMULATION_RUNS               : Total parallel simulation runs per generation
                                (POPULATION_SIZE * MAPS_PER_CANDIDATE).
                                Metric: Simulations count (int).

MAX_SIMULATION_STEPS          : Maximum frame steps allowed per candidate
                                evaluation run.
                                Metric: Ticks/frames (int).

MAP_REGIME_GENERATIONS        : Max generations to train on a single map
                                layout before rotating environments.
                                Metric: Generations count (int).

REGIME_MIN_GENERATIONS        : Minimum generations required on a map before
                                allowing mastery-based early rotation.
                                Metric: Generations count (int).

REGIME_SOLVE_TARGET           : Minimum successful candidate solvers required
                                to trigger early map rotation.
                                Metric: Solvers count (int).

REGIME_TRANSITION_MUTATION_BOOST : Temporary mutation multiplier applied
                                    when transitioning to a new map.
                                    Metric: Scale factor (float).

MAP_DIFFICULTY_MIN            : Minimum sampled path difficulty ratio when
                                generating random training maps.
                                Metric: Ratio [0.0 - 1.0] (float).

MAP_DIFFICULTY_MAX            : Maximum sampled path difficulty ratio when
                                generating random training maps.
                                Metric: Ratio [0.0 - 1.0] (float).

MUTATION_RATE                 : Probability of applying Gaussian weight
                                mutations to offspring networks.
                                Metric: Ratio [0.0 - 1.0] (float).

MUTATION_SCALE                : Standard deviation noise scale applied to
                                weights during mutation ops.
                                Metric: Noise scale (float).

MUTATION_SCALE_MIN            : Minimum adaptive lower floor cap for
                                mutation scale adjustments.
                                Metric: Noise scale (float).

MUTATION_SCALE_MAX            : Maximum adaptive upper ceiling cap for
                                mutation scale adjustments.
                                Metric: Noise scale (float).

MUTATION_ADAPT_WINDOW         : Window of generations evaluated for the 1/5
                                success rule adaptation.
                                Metric: Generations count (int).

STAGNATION_BUMP_GENERATIONS   : Generations without improvement before a
                                mutation scale bump triggers.
                                Metric: Generations count (int).

STAGNATION_BUMP_FACTOR        : Multiplier applied to mutation scale upon
                                reaching stagnation bump threshold.
                                Metric: Multiplier factor (float).

ELITISM_RATIO                 : Ratio of top-scoring candidates copied
                                unchanged into the next generation.
                                Metric: Ratio [0.0 - 1.0] (float).

DEFAULT_PLAYBACK_SPEED        : Initial playback speed multiplier upon
                                booting visualizer GUI.
                                Metric: Speed multiplier (int).

DIST_TO_TIME_BONUS_RATIO      : Relative weight multiplier comparing
                                distance progress to frame time bonus.
                                Metric: Ratio [0.0 - 1.0] (float).

LOST_HP_SCORE_IMPACT_RATIO    : Weighting factor determining how strongly
                                health loss penalizes final score.
                                Metric: Ratio [0.0 - 1.0] (float).

RECORDER_MAX_GENERATIONS      : Rolling metrics memory history cap.
                                Metric: Generations count (int).


[PARALLEL SIMULATION]
-------------------------------------------------------------------------------
SIMULATION_WORKERS            : Number of parallel CPU worker processes for
                                batch candidate evaluation (0 = auto).
                                Metric: Workers count (int).

TRAINING_USE_LOW_PRIORITY     : Drops scheduling priority of worker processes
                                in OS thread scheduler to prevent lag.
                                Metric: Toggle (bool).


[GPU (PYTORCH) TRAINING BACKEND]
-------------------------------------------------------------------------------
TRAINING_BACKEND              : Hardware compute backend ("auto", "gpu",
                                or "cpu").
                                Metric: Backend string (str).


[AUTO-TUNING CONFIGURATION]
-------------------------------------------------------------------------------
AUTO_TUNE                     : Hardware-aware automatic calibration of
                                training scale parameters at startup.
                                Metric: Toggle (bool).

TARGET_GEN_TIME               : Target duration in seconds per generation.
                                Metric: Seconds (float).

AUTO_TUNE_MIN_RUNS            : Absolute lower bound clamp for auto-tuned
                                simulation run budget.
                                Metric: Simulations count (int).

AUTO_TUNE_MAX_RUNS            : Absolute upper bound clamp for auto-tuned
                                simulation run budget.
                                Metric: Simulations count (int).

AUTO_TUNE_PROBE_RUNS          : Calibration runs used for auto-tuning on
                                GPU training backend.
                                Metric: Simulations count (int).

AUTO_TUNE_PROBE_RUNS_CPU      : Calibration runs used for auto-tuning on
                                CPU training backend.
                                Metric: Simulations count (int).


[CURRICULUM (ADAPTIVE DIFFICULTY)]
-------------------------------------------------------------------------------
CURRICULUM_ENABLED            : Activates adaptive difficulty stepping (starts
                                with short paths and scales up).
                                Metric: Toggle (bool).

CURRICULUM_DIFFICULTY_RATIO   : Base wall density used during curriculum
                                map generation.
                                Metric: Ratio [0.0 - 1.0] (float).

CURRICULUM_START_BFS          : Initial target topological path length for
                                early training stages.
                                Metric: Tiles (int).

CURRICULUM_BFS_STEP           : Path length increase applied upon mastering
                                a curriculum difficulty level.
                                Metric: Tiles (int).

CURRICULUM_BFS_WINDOW         : Acceptable path distance window margin when
                                generating curriculum maps.
                                Metric: Tiles (int).

CURRICULUM_MAX_BFS            : Maximum targeted path distance cap for high
                                difficulty curriculum maps.
                                Metric: Tiles (int).

CURRICULUM_MAP_ATTEMPTS       : Retry attempts allowed per regime to match
                                requested curriculum target distance.
                                Metric: Attempts (int).

CURRICULUM_FAILURES_BEFORE_EASE : Consecutive unsolved regimes required
                                  before easing target distance down.
                                  Metric: Regimes count (int).


[GUI ELEMENT LAYOUT RECTANGLES]
-------------------------------------------------------------------------------
LAYOUT_GRID_RECT              : Position and dimensions (x, y, w, h) of
                                the candidate grid viewport section.
                                Metric: Rectangle (int, int, int, int).

LAYOUT_PANEL_RECT             : Position and dimensions (x, y, w, h) of
                                the telemetry overlay panel.
                                Metric: Rectangle (int, int, int, int).

LAYOUT_GRAPH_RECT             : Position and dimensions (x, y, w, h) of
                                the neural network graph panel.
                                Metric: Rectangle (int, int, int, int).

LAYOUT_SCRUBBER_RECT          : Position and dimensions (x, y, w, h) of
                                the interactive scrubber panel.
                                Metric: Rectangle (int, int, int, int).


[HUD TYPOGRAPHY & ELEMENT SIZING]
-------------------------------------------------------------------------------
HUD_PANEL_TITLE_FONT_SIZE     : Font point size for panel header titles.
                                Metric: Points (int).

HUD_PANEL_BODY_FONT_SIZE      : Font point size for panel telemetry text.
                                Metric: Points (int).

HUD_SCRUBBER_BTN_HEIGHT       : Pixel height for scrubber UI buttons.
                                Metric: Pixels (int).

HUD_SCRUBBER_BTN_FONT_SIZE    : Font point size for scrubber button text.
                                Metric: Points (int).

HUD_SCRUBBER_BAR_HEIGHT       : Pixel height for timeline track bars.
                                Metric: Pixels (int).

HUD_SCRUBBER_MARKER_RADIUS    : Pixel radius for timeline handle markers.
                                Metric: Pixels (int).

HUD_GRAPH_NODE_RADIUS         : Pixel radius for neural graph nodes.
                                Metric: Pixels (int).

HUD_GRAPH_FONT_SIZE           : Font point size for neural graph labels.
                                Metric: Points (int).

HUD_GRAPH_LABEL_PADDING       : Spacing padding between nodes and labels.
                                Metric: Pixels (int).


[VISUAL THEME & COLORS]
-------------------------------------------------------------------------------
COLOR_BG                      : Fill color for window background.
                                Metric: RGB (int, int, int).

COLOR_WALL                    : Fill color for wall tile obstacles.
                                Metric: RGB (int, int, int).

COLOR_WALL_BORDER             : Outline color for wall tiles and UI panel
                                borders.
                                Metric: RGB (int, int, int).

COLOR_FLOOR                   : Fill color for walkable floor tiles.
                                Metric: RGB (int, int, int).

COLOR_FLOOR_BORDER            : Outline color for floor grid tile borders.
                                Metric: RGB (int, int, int).

COLOR_START                   : Color for candidate spawn tile and header
                                accent text.
                                Metric: RGB (int, int, int).

COLOR_EXIT                    : Color for target exit tile and top score
                                metrics.
                                Metric: RGB (int, int, int).

COLOR_PLAYER                  : Normal body color for candidates.
                                Metric: RGB (int, int, int).

COLOR_PLAYER_HIGHLIGHT        : Body and frame color for active selected
                                candidate agent.
                                Metric: RGB (int, int, int).

COLOR_PLAYER_TEXT             : Text color for candidate ASCII faces.
                                Metric: RGB (int, int, int).

COLOR_VISION_ARC              : Fill color for vision arc fan polygons.
                                Metric: RGBA (int, int, int, int).

PLAYER_FACE_TEXT_SCALE        : Scale factor for facial expressions relative
                                to candidate body size.
                                Metric: Scale factor (float).

PLAYER_HEADING_LINE_LENGTH    : Scale factor for forward heading line length.
                                Metric: Scale factor (float).

PLAYER_HEADING_LINE_WIDTH     : Pixel width for heading indicator line.
                                Metric: Pixels (int).

COLOR_PLAYER_HEADING_LINE     : Color for forward heading indicator line.
                                Metric: RGBA (int, int, int, int).


[HEALTH BAR & STATUS FRAME COLORS]
-------------------------------------------------------------------------------
COLOR_HEALTH_FULL             : Health bar color when health is above 50%.
                                Metric: RGB (int, int, int).

COLOR_HEALTH_MID              : Health bar color when health is 20% to 50%.
                                Metric: RGB (int, int, int).

COLOR_HEALTH_LOW              : Health bar color when health is under 20%.
                                Metric: RGB (int, int, int).

COLOR_FRAME_SOLVED            : Inset frame color for candidates that
                                successfully reached the exit tile.
                                Metric: RGB (int, int, int).

COLOR_FRAME_DEAD              : Inset frame color for candidates that
                                expired from health depletion.
                                Metric: RGB (int, int, int).


[HUD & ACTIVATION GRAPH COLORS]
-------------------------------------------------------------------------------
COLOR_NODE_INACTIVE           : Color for inactive neural network nodes.
                                Metric: RGB (int, int, int).

COLOR_NODE_ACTIVE             : Color for fully active neural network nodes.
                                Metric: RGB (int, int, int).

COLOR_TIMELINE_BAR            : Background color for timeline track bars.
                                Metric: RGB (int, int, int).

COLOR_MARKER                  : Color for interactive timeline handle markers.
                                Metric: Color RGB (int, int, int).

COLOR_BUTTON                  : Default background color for UI buttons.
                                Metric: RGB (int, int, int).

COLOR_BUTTON_ACTIVE           : Active/pressed color for UI buttons.
                                Metric: RGB (int, int, int).


[CANDIDATE FACIAL EXPRESSIONS]
-------------------------------------------------------------------------------
FACE_WALK                     : Facial expression string rendered during
                                normal walking traversal ("o_o").
                                Metric: Expression string (str).

FACE_WALL                     : Facial expression string rendered during wall
                                impact collisions (">*<").
                                Metric: Expression string (str).

FACE_DEAD                     : Facial expression string rendered when
                                health drops to zero ("T_T").
                                Metric: Expression string (str).

FACE_EXIT                     : Facial expression string rendered when
                                candidate reaches the exit ("^*^").
                                Metric: Expression string (str).
