===============================================================================
                     CONFIGURATION MANUAL & FIELD GUIDE
===============================================================================

[DISPLAY & GRID LAYOUT]
-------------------------------------------------------------------------------
SCREEN_WIDTH                  : Target application display window width.
                                Metric: Pixels (int).

SCREEN_HEIGHT                 : Target application display window height.
                                Metric: Pixels (int).

FPS                           : Target rendering frame rate and simulation
                                frame clock speed limit.
                                Metric: Hertz (int).

GRID_ROWS                     : Number of vertical viewports rendered in the
                                visualizer candidate grid.
                                Metric: Count (int).

GRID_COLS                     : Number of horizontal viewports rendered in the
                                visualizer candidate grid.
                                Metric: Count (int).


[WORLD & MAP PARAMETERS]
-------------------------------------------------------------------------------
MAP_TYPE                      : Selects procedural level generation style
                                ("BRANCHING WALLS" or "RANDOM").
                                Metric: Style string (str).

MAP_WIDTH                     : Level grid width in tile units.
                                Metric: Tiles (int).

MAP_HEIGHT                    : Level grid height in tile units.
                                Metric: Tiles (int).

TILE_SIZE                     : Pixel size of a square tile in Player-
                                Centered tracking mode.
                                Metric: Pixels (int).

WALL_DENSITY                  : Target percentage of inner open area to convert
                                into wall obstacles during generation.
                                Metric: Ratio [0.0 - 1.0] (float).

MAX_MAP_GEN_ATTEMPTS          : Maximum retry attempts to generate a 100%
                                solvable map layout before fallback.
                                Metric: Attempts (int).

MIN_PATH_DIFFICULTY_RATIO     : Minimum required path difficulty ratio between
                                start and exit tiles.
                                Metric: Ratio [0.0 - 1.0] (float).


[SENSORY & VISION ARC]
-------------------------------------------------------------------------------
VISION_RAYS                   : Number of sensor probe rays cast across the
                                candidate's vision fan.
                                Metric: Rays count (int).

VISION_ARC_ANGLE              : Total field-of-view spread angle of the visual
                                sensor fan.
                                Metric: Degrees (float).

VISION_MAX_DIST               : Maximum reach distance of vision rays measured
                                in map tiles.
                                Metric: Tiles (float).

INCLUDE_COMPASS               : Enables two extra directional target compass
                                channels (TG-L, TG-R). Disabling forces
                                agents to navigate using wall rays alone.
                                Metric: Toggle (bool).


[KINEMATICS & PHYSICS]
-------------------------------------------------------------------------------
KINEMATICS_PROFILE            : Selects driving profile ("CAR" for velocity-
                                scaled turns or "TANK" for in-place turns
                                with idle health drain).
                                Metric: Style string (str).

MOVE_SPEED                    : Maximum forward movement distance per tick.
                                Metric: Tiles/tick (float).

TURN_SPEED                    : Maximum steering rotation speed.
                                Metric: Degrees/sec (float).

PLAYER_RADIUS_RATIO           : Scale factor for circular body collision hitbox
                                relative to tile size.
                                Metric: Ratio (float).

PLAYER_CAMERA_ZOOM            : Camera zoom scale factor in Player-Centered
                                tracking mode.
                                Metric: Scale factor (float).

HEALTH_COLL_DMG_PER_FRAME     : Health deducted per frame while touching or
                                colliding with wall tiles.
                                Metric: Damage ratio (float).

HEALTH_IDLE_DMG_PER_FRAME     : Health deducted per frame when standing still
                                or spinning in place.
                                Metric: Damage ratio (float).

HEALTH_RECOVERY_RATIO         : Health restored per unit of distance closed on
                                setting new best exit records.
                                Metric: Recovery ratio (float).

[ANTI-SPIN & STAGNATION GUARDS]
-------------------------------------------------------------------------------
SPIN_PENALTY_ENABLED          : Enables the cumulative turn-angle spin penalty
                                 system. When active, candidates whose
                                 accumulated rotation exceeds
                                 SPIN_ANGLE_THRESHOLD_DEG incur per-frame
                                 damage. The counter resets each frame the
                                 agent's angular delta falls below
                                 SPIN_RESET_ANGLE_DEG.
                                 Metric: Toggle (bool).

SPIN_ANGLE_THRESHOLD_DEG      : Total accumulated absolute rotation in degrees
                                 a candidate may accrue before spin damage
                                 begins. The counter resets to zero on any
                                 frame where the per-step angular delta is
                                 below SPIN_RESET_ANGLE_DEG.
                                 Metric: Degrees (float).

SPIN_RESET_ANGLE_DEG          : Per-frame angular delta threshold in degrees.
                                 If a candidate's turn this frame is below
                                 this value the spin accumulator resets to
                                 zero, clearing continuous spin debt for
                                 agents travelling relatively straight.
                                 Metric: Degrees (float).

SPIN_DMG_PER_FRAME            : Health deducted per frame once the cumulative
                                 spin threshold is exceeded.
                                 Metric: Damage ratio (float).

STAGNATION_ENABLED            : Enables the BFS progress stagnation clock.
                                 When active, candidates failing to improve
                                 their best BFS step-distance within the
                                 stagnation window incur per-frame damage.
                                 Metric: Toggle (bool).

STAGNATION_TIMEOUT_RATIO      : Fraction of MAX_SIMULATION_STEPS allowed
                                 without a new record BFS step-distance before
                                 stagnation drain begins. Scales automatically
                                 when MAX_SIMULATION_STEPS changes.
                                 Stagnation limit = int(MAX_SIMULATION_STEPS
                                 * STAGNATION_TIMEOUT_RATIO).
                                 Metric: Ratio [0.0 - 1.0] (float).

STAGNATION_DMG_PER_FRAME      : Health deducted per frame once the stagnation
                                 timeout window is exceeded without a new BFS
                                 record distance being set.
                                 Metric: Damage ratio (float).


[NEURAL ARCHITECTURE]
-------------------------------------------------------------------------------
NEURAL_HIDDEN_LAYERS          : Number of dense hidden layers in the MLP
                                neural network architecture.
                                Metric: Layers count (int).

NEURAL_NEURONS                : Number of artificial neurons per hidden layer.
                                Metric: Neurons count (int).


[GENETIC ALGORITHM & TRAINING]
-------------------------------------------------------------------------------
LEARNING_GENERATIONS          : Total evolutionary generations simulated
                                during pre-training.
                                Metric: Generations count (int).

POPULATION_SIZE               : Total candidate neural networks evaluated
                                per generation.
                                Metric: Candidates count (int).

MAX_SIMULATION_STEPS          : Maximum frame ticks allowed per candidate run.
                                Metric: Ticks/frames (int).

MAP_REGIME_GENERATIONS        : Maximum generations to train on a single map
                                layout before rotating maps.
                                Metric: Generations count (int).

REGIME_MIN_GENERATIONS        : Minimum generations required on a map before
                                allowing mastery-based early rotation.
                                Metric: Generations count (int).

REGIME_SOLVE_TARGET           : Minimum successful candidate solvers required
                                to trigger early map rotation.
                                Metric: Solvers count (int).

REGIME_TRANSITION_MUTATION_BOOST : Temporary mutation multiplier applied on
                                transitioning to a new map layout.
                                Metric: Scale factor (float).

MAP_DIFFICULTY_MIN            : Minimum sampled path difficulty ratio when
                                generating random training maps.
                                Metric: Ratio [0.0 - 1.0] (float).

MAP_DIFFICULTY_MAX            : Maximum sampled path difficulty ratio when
                                generating random training maps.
                                Metric: Ratio [0.0 - 1.0] (float).

MUTATION_RATE                 : Probability of applying Gaussian mutations to
                                offspring weights.
                                Metric: Ratio [0.0 - 1.0] (float).

MUTATION_SCALE                : Standard deviation noise scale applied to
                                weights during mutation.
                                Metric: Noise scale (float).

ELITISM_RATIO                 : Ratio of top-scoring candidates preserved
                                unchanged into the next generation.
                                Metric: Ratio [0.0 - 1.0] (float).

DEFAULT_PLAYBACK_SPEED        : Initial playback speed multiplier on booting
                                the visualizer GUI.
                                Metric: Speed multiplier (int).

SCRUBBER_ARROW_JUMP_FRAMES    : Number of frames skipped per Arrow Left /
                                 Arrow Right key press during GUI replay
                                 scrubbing.
                                 Metric: Frames (int).

DIST_TO_TIME_BONUS_RATIO      : Relative weight multiplier comparing distance
                                progress to time-saved bonus.
                                Metric: Ratio [0.0 - 1.0] (float).

LOST_HP_SCORE_IMPACT_RATIO    : Weighting factor determining how strongly health
                                loss penalizes fitness score.
                                Metric: Ratio [0.0 - 1.0] (float).


[PARALLEL SIMULATION]
-------------------------------------------------------------------------------
SIMULATION_WORKERS            : Number of parallel CPU worker processes for
                                batch candidate evaluation (0 = auto).
                                Metric: Workers count (int).


[CURRICULUM (ADAPTIVE DIFFICULTY)]
-------------------------------------------------------------------------------
CURRICULUM_ENABLED            : Activates adaptive difficulty stepping (starts
                                with easy short paths and scales up).
                                Metric: Toggle (bool).

CURRICULUM_DIFFICULTY_RATIO   : Base wall density used during curriculum map
                                generation.
                                Metric: Ratio [0.0 - 1.0] (float).

CURRICULUM_START_BFS          : Initial target topological path length for early
                                training stages.
                                Metric: Tiles (int).

CURRICULUM_BFS_STEP           : Path length increase applied upon mastering
                                a curriculum difficulty level.
                                Metric: Tiles (int).

CURRICULUM_BFS_WINDOW         : Acceptable path distance window margin when
                                generating curriculum maps.
                                Metric: Tiles (int).

CURRICULUM_MAX_BFS            : Maximum targeted path distance cap for high
                                difficulty curriculum maps.
                                Metric: Tiles (int).

CURRICULUM_MAP_ATTEMPTS       : Retry attempts allowed per regime to match
                                requested curriculum target distance.
                                Metric: Attempts (int).

CURRICULUM_FAILURES_BEFORE_EASE : Consecutive unsolved regimes required before
                                easing curriculum target distance back down.
                                Metric: Regimes count (int).

LAYOUT_PANEL_RECT             : Position and size (x, y, width, height) of

LAYOUT_GRAPH_RECT             : Position and size (x, y, width, height) of

LAYOUT_SCRUBBER_RECT          : Position and size (x, y, width, height) of
                                the interactive transport scrubber panel.
                                Metric: Rectangle (int, int, int, int).

HUD_SCRUBBER_MARKER_RADIUS    : Pixel radius for timeline handle markers.

HUD_GRAPH_NODE_RADIUS         : Pixel radius for neural network graph nodes.

HUD_GRAPH_FONT_SIZE           : Font point size for neural graph labels.

HUD_GRAPH_LABEL_PADDING       : Spacing padding between graph nodes and

COLOR_FRAME_DEAD              : Viewport inset frame color for candidates
